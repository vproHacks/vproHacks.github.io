# vproHacks.github.io

Personal portfolio site for **Vraj Prajapati**, built with Jekyll and a custom CRT-inspired retro theme.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Open [http://127.0.0.1:4000](http://127.0.0.1:4000).

Click the **VPRO** logo in the nav to replay the CRT intro anytime. First visit plays automatically once (`vpro_intro_seen` in localStorage).

## Theme

The design system lives in [`assets/css/retro.css`](assets/css/retro.css), ported from [`retro-site-template/`](retro-site-template/) (reference only; excluded from the site build).

Logo assets: [`assets/images/vpro-logo.svg`](assets/images/vpro-logo.svg), [`assets/images/favicon.svg`](assets/images/favicon.svg).
